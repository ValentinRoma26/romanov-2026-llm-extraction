# The paper for this tutorial

This tutorial uses a single paper, referred to throughout as **ref13**.

**ref13** is a study of calcium and magnesium binding to bovine cardiac troponin,
measured by scintillation counting at 4 °C. It reports binding constants for
isolated troponin C, the TnI·TnC complex, and the whole troponin complex — which
is exactly the kind of data the extraction task is about.
