# Source documents (immutable)

Place original, unmodified source documents here. **Do not edit these files** —
every downstream artifact should be reproducible from this folder.

Document provenance for each source:

- **Source:** where the data came from (database, API, collaborator, …)
- **License / terms:** redistribution rights and any restrictions
- **Date retrieved:** when it was pulled
- **Access notes:** DUAs, embargoes, or de-identification applied
